# Security Policy

## Supported Versions

Gebruik dit gedeelte om mensen te laten weten welke versies van uw project momenteel worden ondersteund met beveiligingsupdates.

| Versie  | Ondersteund          |
| ------- | ------------------ |
| 5.1.x   | :white_check_mark: |
| 5.0.x   | :x:                |
| 4.0.x   | :white_check_mark: |
| < 4.0   | :x:                |

## Een kwetsbaarheid melden

Gebruik dit gedeelte om mensen te vertellen hoe ze een beveiligingslek kunnen melden.

Vertel ze waar ze terecht kunnen, hoe vaak ze een update over een gemeld beveiligingslek kunnen verwachten, wat ze kunnen verwachten als het lek wordt geaccepteerd of afgewezen, enzovoort.
